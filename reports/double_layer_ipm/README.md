# Double-layer IPM design study

> 두 겹의 V형 영구자석을 어떻게 배치해야 토크를 유지하면서 자석 사용량과 토크리플을 줄일 수 있을까?

![Double-layer IPM rotor geometry: low-ripple and high-ripple designs](05_inner_angle_ripple_physics/figures/figure_01.png)

이 프로젝트에서는 pyFEMM으로 **double-layer V-IPM rotor**를 생성하고, 자석의
내·외측 각도와 길이·두께를 바꾸며 전자기 성능을 비교했다. 위 그림은
비슷한 자석량을 사용하면서도 토크리플이 크게 달라진 두 설계다. 같은
더블레이어 구조라도 자석의 각도와 배치가 공극 자속, 전단응력, 평균토크와
리플을 크게 바꿀 수 있다는 것이 이 연구의 출발점이다.

## 무엇을 설계했는가

기존의 한 겹 V-IPM 자석을 두 개의 레이어로 나누고, 각 레이어를 독립적으로
조절할 수 있는 파라메트릭 로터 모델을 만들었다. 주로 다음 설계변수를
검토했다.

- inner/outer V-angle: 두 자석층이 d축을 향해 벌어지는 각도
- inner/outer magnet length: 각 레이어가 만드는 PM 자속의 크기
- magnet thickness와 면적비: 자석 사용량과 자속밀도의 절충
- rotor position과 commutation condition: 한 점의 토크가 아니라 토크 파형을 계산하기 위한 운전 조건

평가지표는 **평균토크**, **토크리플 pk-pk**, **자석 사용량**, 그리고
`평균토크/자석면적`이었다. 최종 단계에서는 토크 숫자만 비교하지 않고
공극자속 FFT와 Maxwell stress까지 확인해 리플이 발생하는 물리적 이유를
추적했다.

## DOE를 어떻게 확장했는가

처음부터 모든 변수를 촘촘하게 훑으면 FEMM 계산량이 너무 커진다. 따라서
작은 DOE로 가능성을 확인한 뒤, 부족한 정보를 다음 실험에서 보완하는 방식으로
설계공간을 단계적으로 확장했다.

```text
① 결합형 4인자 CCF 50점
   자석량을 줄인 double-layer 구조의 가능성 확인
                 ↓
② 각도 범위를 55–90°로 확장한 FEMM DOE
   DNN ensemble로 10,000개 가상 후보 탐색
                 ↓
③ 목적별 후보 5개를 실제 FEMM으로 재검증
   surrogate의 예측 오차와 실제 우위 확인
                 ↓
④ inner/outer angle을 분리한 6인자 Sobol 64점
   각 레이어의 역할과 변수 민감도 분리
                 ↓
⑤ 저리플–고리플 설계쌍 물리 비교
   토크 FFT → 공극자속 FFT → Maxwell stress로 원인 추적
```

이 흐름에서 대리모델은 FEMM을 대체하는 최종 해답이 아니라, 비싼 FEMM
재해석을 어디에 집중할지 정하는 탐색 도구로 사용했다.

## 결론

### 1. Double-layer 구조는 자석을 줄이면서도 경쟁력 있는 토크를 만들 수 있다

초기 CCF 50점 해석에서 Run 19는 비교 싱글레이어에 가까운 평균토크
**46.00 N·m**를 유지하면서 자석량을 약 **18% 줄였다**. Run 22는
평균토크 **42.39 N·m**, 리플 **3.43 N·m pk-pk**로 저리플 방향의 다른
절충점을 만들었다. 즉, 더블레이어의 장점은 하나의 절대 최적점보다
자석량–평균토크–리플 사이에 선택 가능한 Pareto 영역을 넓힌다는 데 있다.

### 2. 설계공간을 넓히면 싱글레이어보다 높은 토크의 후보도 찾을 수 있다

55–90° 확장 DOE와 DNN 탐색 후 실제 FEMM으로 재검증한 C6038은
**53.45 N·m / 10.09 N·m pk-pk**를 기록했다. 비교 싱글레이어 최대점보다
자석을 약 **9% 적게 사용하면서 평균토크는 약 4.7% 높았다**. 최대토크만
노리지 않은 C5983은 **47.67 N·m / 5.10 N·m pk-pk**로 더 실용적인
균형점이었다.

검증 5점의 예측 오차는 평균토크 RMSE **0.99 N·m**, 리플 RMSE
**0.37 N·m**였다. 전체 경향 탐색에는 surrogate가 유효했지만, 저리플로
예측된 일부 후보의 우위는 FEMM에서 재현되지 않았다. 따라서 최종 설계
판정에는 실제 FEMM 재검증이 필요하다.

### 3. 최고·최저 설계의 토크 차이에는 PM 자속 기본파 감소가 직접 관찰된다

최저토크 Run 31은 최고토크 Run 24보다 평균토크가 **31.4% 낮았다**.
0 A 공극자속의 공간 2차 기본파도 **0.289 T**로, 최고 설계의 **0.549 T** 중
**52.6%**에 불과했다. 이는 낮은 토크의 중요한 원인으로 유효 PM 자속의
감소를 지목할 수 있다는 뜻이다.

다만 무부하 자속만으로 `Ld`, `Lq`, 포화 및 릴럭턴스 토크의 차이까지 설명할
수는 없다. 이 부분은 d축·q축 전류를 분리한 증분 인덕턴스 해석이 필요한
미완료 과제다.

### 4. 두 자석층은 같은 역할을 하지 않는다

내·외측각을 독립변수로 분리한 Sobol 64점에서는 자석 길이와 두께 계열이
평균토크에 큰 영향을 보인 반면, **inner angle은 토크리플과 복합 토크품질에
강한 경향**을 보였다. `평균토크/토크리플` 지표에 대한 inner-angle
Spearman 상관은 **0.818**, 진단용 Sobol 1차 지수는 **0.562**였다.

outer angle은 절대토크보다 자석면적당 토크에서 중요한 후보로 나타났다.
따라서 두 각도를 하나의 결합변수로 조절하기보다 독립적으로 최적화하는 것이
타당하다. 단, 64점 surrogate와 고정 commutation 조건에서 얻은 민감도이므로
이 수치 자체를 인과관계로 단정하지 않는다.

### 5. 큰 토크리플은 공극 고조파와 Maxwell stress 변화까지 이어진다

자석량이 비슷한 저리플·고리플 설계쌍을 비교했을 때 리플률은 **6.33%에서
37.37%**로 증가했고, 고리플 형상의 토크밀도는 **7.75% 낮았다**. 동시에
자석면적당 비기본파 RMS는 **84.1% 증가**했다. 토크 FFT, 공극자속 FFT,
전단응력과 반경압력 진단이 모두 같은 방향을 보여, 형상 변화가 공극 고조파와
응력 분포를 거쳐 토크리플로 연결된다는 설명 사슬을 지지한다.

그러나 비교쌍은 자석면적이 **2.48%** 다르고 다른 변수도 완전히 같지 않다.
따라서 현재 결과는 inner angle의 중요성을 뒷받침하지만, inner angle 하나의
순수 인과효과를 확정하지는 않는다.

## 해석 범위와 주의점

- 결과는 2D FEMM과 각 실험의 고정 운전점에 기반한다.
- surrogate의 최적 후보는 별도 FEMM 재해석을 통과한 값만 검증 결과로 구분했다.
- 열, 구조, 철손, 코깅, 약계자 전 영역은 아직 통합하지 않았다.
- Sobol 및 상관계수는 제한된 표본에서 얻은 설계 가설이며 단독으로 인과관계를 뜻하지 않는다.
